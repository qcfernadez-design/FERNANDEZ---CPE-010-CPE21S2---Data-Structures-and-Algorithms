## 🎯 Course Objectives
The course aims to provide an understanding of analyzing algorithms and their complexity. It enables the development of data structures including **Abstract Data Types, Linked Lists, Stacks, Queues, Trees, and Graphs** using the **C++ programming language**. 

Additionally, mathematical techniques are used to analyze algorithm efficiency and common operations on data structures. Students implement algorithms and conduct real-system performance measurements towards the attainment of **SDG 9 – Industry, Innovation, and Infrastructure**.

---

## 💡 Course Intended Learning Outcomes (C.I.L.O.)
1. **Apply** fundamental data structures and techniques to solve engineering-related problems through algorithm design.
2. **Design** efficient algorithms and analyze their complexity.
3. **Build** efficient algorithms based on selected data structures using clean programming styles in C++.
